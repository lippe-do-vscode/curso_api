# API de Cursos
API para gerenciamento de professores e cursos

## Tecnologias 
- Javascript
 - Node js
- Mysql
- Express

## Endpoints
- `POST /professores` - Criar um professor
- `GET /professores` - Lista de professores
- `POST /cursos` - Cria um curso
- `GET /cursos` - Lista cursos
- `DELETE /cursos/:id` - Delete um curso por id
